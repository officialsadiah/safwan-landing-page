# Safwan — UI/UX Portfolio Landing Page

A responsive single-page portfolio website for a UI/UX designer, built from a visual design mockup.

## Tech Stack

- HTML5
- CSS3 (custom + responsive)
- Bootstrap 5 (grid, navbar, cards)

## Page Sections

- Navbar with responsive toggle (Bootstrap)
- Hero/Banner with text overlay
- Services — 3-card grid (UI/UX Design, Mobile App Design, Web Design)
- About Me — image grid + bio + skills bar
- Projects — 3-card carousel with navigation arrows
- Portfolio Gallery — 4-card grid with category filter tabs
- Client Testimonials — review cards with star ratings
- Contact Form
- Blog / Articles — 3-card grid
- Footer

## Highlights

- Fully responsive layout (mobile → desktop)
- Custom CSS with hover animations, transitions, and micro-interactions
- Bootstrap grid system for all card layouts
- Google Fonts (Vollkorn, Jost, Poppins)
- CSS-only underline animations on portfolio filter tabs
